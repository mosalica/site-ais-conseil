# AIS Conseil — site vitrine

Site statique bilingue (FR/EN) d'AIS Conseil, conseil en cybersécurité et en IA à Dieppe / Moncton (Nouveau-Brunswick).

Signature : Adopter. Innover. Sécuriser. / Adopt. Innovate. Secure.

Principe fondateur : « L'agent ne remplace jamais l'humain. Il est au service de l'humain : il allège ses tâches en automatisant certaines actions, et laisse toujours l'humain décider. »

## Structure

- Pages françaises à la racine : `index.html`, `services.html`, `donnees-ia.html`, `methode-demo.html`, `a-propos.html`, `contact.html`
- Pages anglaises dans `en/` : `index.html`, `services.html`, `data-ai.html`, `method-demo.html`, `about.html`, `contact.html`
- `styles.css` : feuille de style unique, aucune ressource externe, aucun traceur
- `CNAME` : domaine personnalisé GitHub Pages — aisconseil.ca

## Mise en ligne

Hébergement : GitHub Pages, branche `main`, racine du dépôt. DNS géré chez WHC (registraire du domaine aisconseil.ca).

Le formulaire de contact est dessiné mais non branché ; il sera relié à un service de réception dans une prochaine étape.
